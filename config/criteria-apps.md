# Критерії оцінки: мобільні застосунки

Версія: v0.0
Дата: —

**Заповнюється пізніше.** Цей файл — заглушка тієї ж структури, що й `config/criteria-passive-income.md` (кожен пункт: що перевіряти, що вважається провалом, `rejection_code`), тюнингу підлягає окремо для треку app-ideas.

Джерело: PLAN.md, Фаза 2 (кінець розділу) — «для criteria-apps.md — окремий чек-лист (розмір ринку, конкуренція, монетизація; зусилля очікувані, не мінімізовані) — заповнюється пізніше».

---

## Майбутні осі оцінки (перелік із плану, без деталізації)

1. **Розмір ринку** — потенційна аудиторія застосунку, розмір ніші.
2. **Конкуренція** — скільки подібних застосунків уже існує, наскільки вони закриті нішу.
3. **Монетизація** — реалістична модель заробітку (підписка, реклама, разова покупка тощо).
4. **Очікувані зусилля** — зусилля на розробку/підтримку оцінюються як очікувані, а не мінімізовані (на відміну від «автономності» в треку passive-income, тут явно враховується, що застосунок вимагає активної розробки).
