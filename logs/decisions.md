# Журнал рішень системи

Журнал важливих рішень системи (не пов'язаних безпосередньо з дедуплікацією — для тих див. `logs/dedup-decisions.md`). Наприклад: зміни критеріїв, ручні втручання, тюнинг промптів, рішення щодо докупки інструментів.

## Формат запису

```
### YYYY-MM-DD — <хто/який джоб>

**Рішення:** ...

**Обґрунтування:** ...
```
